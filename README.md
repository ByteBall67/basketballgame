# Zane Arcade

This folder contains the current basketball arcade project and its game collection.

## Live demo

https://basketballgame-b9b.pages.dev/

## Included in this folder

- `index.html` – main arcade landing page
- `bbgjs/` – JavaScript game files
- `bbgp/` – additional game project files

## Local use

Open `index.html` in a browser, or use the live Pages deployment above.
