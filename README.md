# Zane Arcade

This folder contains the Zane Arcade landing page, basketball game, and Soccer Showdown.

## Live demo

https://basketballgame-b9b.pages.dev/

## Included in this folder

- `index.html` – main arcade landing page
- `bbgjs/` – JavaScript game files
- `bbgp/` – additional game project files
- `soccer-showdown/` – 1v1 soccer game against a bot

## Local use

Open `index.html` in a browser, or open `soccer-showdown/index.html` to play Soccer Showdown.
Choose one of five bot levels, move with the arrow keys, hold D near the ball to keep it close while moving, hold and release Space to charge and shoot, and press Alt near the bot to try a steal.
